# 新疆需求说明书

`xinjiang-requirements.docx` 是用户提供的《附件1-XX项目需求说明书V1.0.docx》的原始副本。保留作为导出的样式、页面、章节和参考因子表来源，不直接修改。

导出入口：`POST /api/export-word`，`exportTemplate: "xinjiang"`。实现位于 `server/xinjiang-word-export.js`。

- 正文六章依次为需求说明、系统现状、功能架构图、功能需求、非功能性需求（可选）、附加值调整因子说明。
- 第4章下的一级、二级、三级模块分别使用原模板的 Word 标题2、3、4，功能过程使用标题5。如输入有四级模块，保留为标题5，功能过程顺延到标题6。
- 标题继承模板的多级编号。图题使用 `STYLEREF` 章号和 `SEQ` 顺序号，缓存为“图 4.1 功能名称时序图”。图和图题保持在一起，目录含1～6级标题，设置为打开时更新域。
- `sequenceDiagrams[].processIndex` 为原始功能过程序号，用来区分跨模块同名功能；兼容没有序号的旧客户端，按名称和出现次序匹配。
- 需求类型只采用明确的 `requirementType` / `changeType` 或功能名称末尾的类型标记；未提供时显示“需求类型待确认”，不会把“删除数据”等操作名误判为删除需求。
- 缺失的背景、架构图、非功能性需求及因子取值标为待补充；原模板红色说明、蓝色示例和示例图片不进入正文。正式参考因子表保留。

验证：`npm run test:word-xinjiang`。测试覆盖原样式保留、标题层级、图题、模块切换、同名功能、缺图与实际导出路由。
